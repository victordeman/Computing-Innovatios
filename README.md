# Computing Innovation and New Technologies Course Website

This repository contains the static website for the undergraduate course **"Computing Innovation and New Technologies"**.

The site is built with plain HTML and [Tailwind CSS](https://tailwindcss.com/) (via CDN) to ensure a modern, professional, and responsive academic aesthetic.

## Features
- **Clean Academic Style:** Navy blue branding, professional typography, and generous white space.
- **Responsive Design:** Fully functional on mobile, tablet, and desktop devices.
- **Syllabus & Schedule:** Detailed 14-week curriculum and assessment breakdown.
- **Resources:** Links to recommended books and external computing resources.
- **Static & Fast:** No build step required; instantly deployable to GitHub Pages.

## Deployment Instructions

To deploy this website to GitHub Pages:

1. **Create a GitHub Repository:** Name it `Computing-Innovatios` (or your preferred name).
2. **Push Files:** Upload or push all `.html` files and this `README.md` to the `main` branch.
   - `index.html`
   - `syllabus.html`
   - `schedule.html`
   - `lectures.html`
   - `projects.html`
   - `resources.html`
   - `staff.html`
   - `faq.html`
3. **Enable GitHub Pages:**
   - Go to your repository **Settings**.
   - Click on **Pages** in the left sidebar.
   - Under **Build and deployment > Branch**, select `main` and click **Save**.
4. **Live Site:** Your site will be live at `https://[your-username].github.io/Computing-Innovatios/` (replace `[your-username]` with your actual GitHub username).
